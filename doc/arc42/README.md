## 給修改文件的人

這份文件描述的是**現況**，不是願景。每個論述盡量指到具體的檔案與行號，
讀者應該能照著打開原始碼驗證。如果程式改了而這裡沒改，以原始碼為準 ——
發現不一致時請更新這裡，或至少在該處註明。

日常操作（怎麼啟動、怎麼測、編碼規則、最容易踩的地雷）寫在根目錄的
`CLAUDE.md`，那份是給「現在就要動手」的人看的，這份是給「想搞懂為什麼」的人看的。
